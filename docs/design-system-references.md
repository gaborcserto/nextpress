# DS-01 references and skills

References inform principles and interactions. Product requirements, actual editorial content and verified behavior govern implementation. External website inspection used page content and documentation unless explicitly described as a screenshot or Figma metadata review. Exact rendered colors, breakpoints, spacing and live interaction fidelity remain unverified for these sites.

## Design references

| Reference                                                                                                              | Evidence and apply                                                                                                                                                                                                                                                                                                                                                                                                                                    | Avoid or defer                                                                                                                                                              |
| ---------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [daisyUI](https://daisyui.com/)                                                                                        | Themeable component classes fit existing Admin ownership. Use its variants as a CSS vocabulary and compare computed control sizing and states across themes.                                                                                                                                                                                                                                                                                          | Avoid mixing ad hoc variants with an additional global component library.                                                                                                   |
| [TailAdmin template survey](https://tailadmin.com/blog/free-html-admin-dashboard)                                      | Dashboard, table and toolbar examples prompt consistent grouping, alignment and management density. Use comparative layouts when checking discoverability.                                                                                                                                                                                                                                                                                            | Reject the crowded analytics-first dashboard, generic widgets and decorative KPI rows for editorial work.                                                                   |
| [MUI DateTimePicker](https://mui.com/x/react-date-pickers/date-time-picker/)                                           | The documented desktop/mobile and field workflows offer a comparison for consistent typed entry and a distinct picker affordance. Borrow legible visual hierarchy and predictable calendar/time action positions.                                                                                                                                                                                                                                     | Reject a MUI dependency and preserve explicit TIME-01 timezone and overlap controls.                                                                                        |
| [Coherent Design System](https://www.figma.com/design/TqmFI2xnVULLcQZoMLniBh/Coherent-Design-System--CDS---Community-) | Connector metadata verified separate Colors, Elevation, Fonts, Inputs, Drawer/Rail and Popover pages with documented anatomy. Input examples distinguish field anatomy; navigation and popover examples label component measurements. Adopt the documentation structure for anatomy, variants and states.                                                                                                                                             | Avoid adopting the sample 280px drawer or 424px popover as NextPress defaults. Metadata establishes structure and measures, with no claims about runtime keyboard behavior. |
| [SnapSoft careers](https://snapsoft.io/careers)                                                                        | Distinct lead, media, successive culture/value sections and recurring headings establish a clear composition in the page structure. Translate the rhythm into one confident Modern editorial lead, image-led groups where media exists, calm contrasting sections, and a substantial footer. Classic can use the sequencing in a quieter serif composition. At narrow sizes preserve the order in a single column and avoid empty media placeholders. | Do not copy careers messaging, brand art, recruiting funnel, motion or exact composition. Palette proposals are NextPress choices.                                          |
| [iamrob.in](https://iamrob.in/)                                                                                        | Personal editorial hierarchy is a useful check for strong headlines, concise labels and scannable ordered entries. Favor this quieter direction for Minimal.                                                                                                                                                                                                                                                                                          | Avoid portfolio-specific framing and assuming its navigation fits a configurable CMS.                                                                                       |
| [Val Head writing](https://valhead.com/blog/)                                                                          | Straightforward dated entries and older-post navigation support Classic/Minimal archive scanning. The reduced-motion and accessible-animation writing supports functional motion only.                                                                                                                                                                                                                                                                | Avoid applying the author's layout or adding editorial animation.                                                                                                           |
| [Vercel blog templates](https://vercel.com/templates/blog)                                                             | Compare editorial starting points for image-led and text-first density. Use a common audit fixture to check how each NextPress preset expresses lead, cards and footer.                                                                                                                                                                                                                                                                               | Avoid adopting starter code or hosted-provider assumptions.                                                                                                                 |
| [Minimal Gallery](https://minimal.gallery/)                                                                            | Use the curated collection to find examples of image rhythm and constrained navigation; test individual sites before borrowing a visual pattern.                                                                                                                                                                                                                                                                                                      | Gallery tiles do not establish usability or behavior.                                                                                                                       |
| [Land-book](https://land-book.com/)                                                                                    | Direct review unavailable through the web reader. Defer as a discovery source until an individual relevant editorial example can be inspected.                                                                                                                                                                                                                                                                                                        | No visual or interaction conclusion.                                                                                                                                        |
| [Deadline](https://deadline.com/)                                                                                      | Direct review unavailable through the web reader. Its potential role is a high-density news comparison, pending inspection.                                                                                                                                                                                                                                                                                                                           | No confirmed hierarchy, style or mobile observation.                                                                                                                        |

## Skill decisions

| Source                                                                                                                                                                                                                                                                  | Reviewed workflow and value                                                                                                                                                                                                                                                                 | Recommendation                                                                                               |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| [Anthropic frontend-design skill](https://raw.githubusercontent.com/anthropics/skills/main/skills/frontend-design/SKILL.md)                                                                                                                                             | Grounds aesthetic choices in subject matter, actual copy and a deliberate type/palette strategy. Useful for Modern and Classic direction. NextPress already has preset and localization boundaries; treat aesthetic risks as contextual.                                                    | **REFERENCE** for visual critique.                                                                           |
| [UI UX Pro Max skill template](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/main/src/ui-ux-pro-max/templates/base/skill-content.md)                                                                                                                     | Defines focused UX and stack searches plus Python-generated design recommendations and optional persisted overrides. Useful prompts include obscured focus, drag alternatives and error summary. Generated palettes and patterns need evidence and overlap with the existing specification. | **DEFER** tooling and persistence. Reference focused audit prompts.                                          |
| [Impeccable](https://github.com/pbakaus/impeccable)                                                                                                                                                                                                                     | Published audit, critique, adapt and harden workflows guide narrow-screen, overflow, localization and edge-state reviews. Design documentation is already owned by DS-01. Live tooling and automatic detector rules can introduce unrelated changes.                                        | **ADAPT** review language only. Reject installation, live edits and mandatory detector criteria.             |
| [ibelick Baseline UI](https://raw.githubusercontent.com/ibelick/ui-skills/main/skills/baseline-ui/SKILL.md)                                                                                                                                                             | File-scoped checklist covers sizing, safe areas, empty states, tabular numbers, focus primitives and token reuse. Existing frontend-design and readability rules overlap.                                                                                                                   | **ADAPT** checklist items with visible benefits. Reject compulsory third-party primitive and motion imports. |
| [Vercel Web Interface Guidelines skill](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines) and its [bundled rules](https://raw.githubusercontent.com/vercel-labs/agent-skills/main/skills/web-design-guidelines/references/command.md) | Pinned rule snapshot and file/line review are useful for visible focus, inline error associations, long strings and reduced motion. Existing React and verification skills own implementation and review workflow.                                                                          | **ADOPT** selected review criteria in batch acceptance, with native behavior and WCAG as the authority.      |
| [Chrome modern web guidance](https://developer.chrome.com/docs/modern-web-guidance)                                                                                                                                                                                     | Native capability and Baseline guidance provides a starting point for responsive images, layout, and capability gating. Test actual target browsers before adopting feature combinations.                                                                                                   | **REFERENCE** for native-first reviews, especially NATIVE-01E.                                               |

The audit reviewed skill texts, published workflow documentation and local conventions. External scripts, installers and repositories were not executed, installed or added as dependencies. The owned workflow remains [frontend-design](../.agents/skills/frontend-design/SKILL.md), [React](../.agents/skills/nextpress-react/SKILL.md) and [verification](../.agents/skills/nextpress-verification/SKILL.md).
