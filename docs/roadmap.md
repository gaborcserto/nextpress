## Future Admin and publishing candidates

These are roadmap candidates for later prioritization, not approved implementation requirements. The SocialHub [API settings reference](https://social-media-dashboard-kit-code.vercel.app/settings/api) and [MUI X Date Time Picker](https://mui.com/x/react-date-pickers/date-time-picker/) are interaction and information-design references only; NextPress should continue using its existing design system. The Kit Review Admin screenshots supplied during design review are local visual references; no source URL was provided.

### Site branding and SEO

- Logo and favicon upload and management.
- Dedicated SEO settings, meta title templates, default descriptions and Open Graph image selection/upload through Media Library.
- Search indexing and canonical URL configuration.
- Public website preview or View Site action.

### Editorial workflows

- Explicit author assignment and management, with distinct creator and last-modified-by metadata.
- Author-based filtering, editorial activity history, recent activity dashboard and scheduled content overview.

### Public website features

- RSS feed and social profile links.
- Template-dependent reading progress indicator.
- Code syntax highlighting and image loading/performance configuration.

### Analytics and integrations

- Analytics provider configuration, privacy-aware visitor analytics, pageview and content performance statistics.
- External integrations, secure API key management and optional provider-based AI functionality.

### Community and publishing extensions

- Comments, moderation and spam protection.
- Newsletter subscriptions, email delivery provider configuration, double opt-in and subscriber management.

### Administration and portability

- Content export/import, backup/recovery workflows and integration management.

### Security-sensitive proposals

The following ideas need separate threat, privacy, authorization, audit and recovery review before any implementation decision: arbitrary custom head/body code injection; bulk destructive content deletion; external API credential storage; third-party script execution; analytics and personal data collection.

## TEST-01 evidence

The local report `.notes/audits/nextpress-test-stability-report.md` records a fix to asynchronous test synchronization and fake-timer interaction in `PrivateDraftBoundary` tests while preserving assertions and application behavior. It reports 430 Admin tests passed locally, three Admin V8 coverage runs, full Admin tests/lint/typecheck, and full monorepo `npm test` (with some Turbo cache reuse). GitHub Actions passing was subsequently confirmed by the user. These statements distinguish local report evidence from hosted CI confirmation; this document does not claim every suite was independently rerun uncached.

## CI-01 historical scope

At the original CI-01 baseline, GitHub Actions runs were reported at approximately 6–9 minutes. The planned assessment covered task durations, caching, duplicate work, workers, parallelism, affected-workspace execution, resource contention, stability, and cache invalidation.

The original target was roughly 3–5 minutes on typical changes, not a guarantee. CI-OPT-01 is now accepted with GO; additional comparable performance and cache measurements are optional monitoring. Required lint, typecheck, tests, coverage, builds, security checks, and appropriate full-repository verification remain applicable.

## FUNC-01 scope

Audit functional completeness across Admin, API, Public Web, DB, and shared contracts. Separately review directory organization, feature boundaries, screens/forms, reusable components, hooks, services, types/constants, public exports and deep imports, circular dependencies, component responsibilities, test placement, Next.js server/client boundaries, and workspace ownership. Use `.references/` as supporting material. Do not prescribe one folder per component or mandatory barrels. Separate functional gaps from structural code-quality issues. FUNC-01 is audit-only.
