# NextPress documentation

This directory is the tracked reference for product direction, verified implementation, architecture, operating the repository, and development history.

| Document                                      | Purpose                                                                                      |
| --------------------------------------------- | -------------------------------------------------------------------------------------------- |
| [Vision](vision.md)                           | Product goals, principles, and exploratory ideas                                             |
| [Current state](current-state.md)             | Evidence-based implementation snapshot and gaps                                              |
| [Features](features.md)                       | Current and intended CMS capability inventory                                                |
| [Roadmap](roadmap.md)                         | Phase status, dependencies, and next work                                                    |
| [Architecture](architecture.md)               | Implemented workspace and runtime boundaries                                                 |
| [Development](development.md)                 | Local setup and verification workflow                                                        |
| [Deployment](deployment.md)                   | Production configuration and readiness considerations                                        |
| [Changelog](changelog.md)                     | Milestone-level development history                                                          |
| [Design system audit](design-system-audit.md) | DS-01 findings and links to the specification, inventory, references and implementation plan |
| [Decisions](decisions/README.md)              | Lightweight architecture decision records                                                    |

Tracked docs describe confirmed behavior and accepted direction. Local `.notes/` holds investigations and temporary reports; `.references/` holds research and examples. Neither is automatically part of the product documentation.
